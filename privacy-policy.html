Политика конфиденциальности приложения «Таро дня»

Дата последнего обновления: 20 августа 2026 г.

Это приложение разработано с уважением к твоей приватности. Ниже подробно описано, какие данные обрабатываются и зачем.

1. Какие данные собирает само приложение

Приложение «Таро дня» не требует регистрации и не собирает личных данных пользователя (имя, email, телефон). Всё, что связано с использованием приложения — открытые карты, история, статус подписки, серия дней подряд — хранится локально на устройстве и не передаётся на сервера разработчика, поскольку у приложения нет собственного сервера.

2. Данные, которые собирают сторонние сервисы

Приложение использует сторонние SDK для рекламы и (в дальнейшем) для приёма платежей.

Yandex Mobile Ads SDK (показ рекламы)

  • Рекламный идентификатор устройства (Advertising ID)
  • Технические данные устройства (модель, версия ОС, язык, регион)
  • Данные о взаимодействии с рекламными объявлениями
  • IP-адрес (для приблизительного геотаргетинга)

RuStore Pay SDK (при оформлении подписки)

  • Данные о транзакции (сумма, дата, статус платежа)
  • Приложение не получает и не хранит данные банковской карты

3. Уведомления

Push-уведомления формируются локально на устройстве и не требуют передачи персональных данных на сервер.

4. Права пользователя

  • Отключить персонализированную рекламу в настройках устройства
  • Удалить приложение — вся локальная история будет удалена
  • Отозвать разрешения приложения в настройках устройства

5. Возрастные ограничения

Приложение не предназначено для детей младше 12 лет.
