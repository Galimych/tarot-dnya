# Политика конфиденциальности приложения «Таро дня»

Дата последнего обновления: 20 августа 2026 г.

Это приложение разработано с уважением к твоей приватности. Ниже подробно
описано, какие данные обрабатываются и зачем.

## 1. Какие данные собирает само приложение

Приложение «Таро дня» **не требует регистрации** и не собирает личных
данных пользователя (имя, email, телефон). Всё, что связано с
использованием приложения — открытые карты, история, статус подписки,
серия дней подряд — **хранится локально на устройстве** и не передаётся
на сервера разработчика, поскольку у приложения нет собственного сервера.

## 2. Данные, которые собирают сторонние сервисы

Приложение использует сторонние SDK для рекламы и (в дальнейшем) для
приёма платежей. Эти сервисы могут собирать следующие данные в
соответствии со своими собственными политиками конфиденциальности:

### Yandex Mobile Ads SDK (показ рекламы)
- Рекламный идентификатор устройства (Advertising ID)
- Технические данные устройства (модель, версия ОС, язык, регион)
- Данные о взаимодействии с рекламными объявлениями (показы, клики,
  досмотры rewarded-видео)
- IP-адрес (для приблизительного геотаргетинга)

Подробнее: [политика конфиденциальности Яндекса](https://yandex.ru/legal/confidential/)

### RuStore Pay SDK (при оформлении подписки, если применимо)
- Данные о транзакции (сумма, дата, статус платежа)
- Приложение **не получает и не хранит** данные банковской карты — они
  обрабатываются платёжной системой RuStore напрямую

Подробнее: [политика конфиденциальности RuStore](https://www.rustore.ru/legal/privacy_policy)

## 3. Уведомления

Если пользователь разрешает push-уведомления, приложение отправляет
локальные напоминания («Твоя карта дня готова»). Эти уведомления
формируются на устройстве и не требуют передачи персональных данных
на сервер.

## 4. Права пользователя

Пользователь может в любой момент:
- Отключить показ персонализированной рекламы в настройках устройства
  (раздел «Реклама» в настройках Android)
- Удалить приложение — вся локально хранимая история и прогресс будут
  удалены вместе с приложением
- Отозвать согласие на обработку данных, отключив разрешения приложения
  в настройках устройства

## 5. Возрастные ограничения

Приложение не предназначено для детей младше 12 лет и не собирает
целенаправленно данные несовершеннолетних.

## 6. Изменения политики

При существенных изменениях в этой политике пользователи будут уведомлены
через обновление приложения в RuStore.
